An **End-to-End Machine Learning Project** to predict whether a bank’s customer will churn (leave the bank) or not.  
The project demonstrates the complete ML pipeline — from **data preprocessing and visualization to feature engineering, model building, and evaluation** using real-world banking data.  

---

## 🔎 Project Purpose
Customer churn is a critical issue in the banking sector as it directly affects revenue and growth.  
This project was designed to:
- Identify key factors influencing customer churn.  
- Build predictive models to classify whether a customer is likely to leave.  
- Evaluate multiple ML models to find the best-performing one.  
- Provide banks with insights to improve retention strategies.

## 📑 Dataset
- **File Type**: Excel (`.xlsx`)  
- **File Name**: `Banking_Customer_Churn.xlsx`  

The dataset includes:
- Customer demographics (Age, Gender, Geography)  
- Account information (Balance, Tenure, Number of Products, Credit Score)  
- Behavioral attributes (IsActiveMember, Estimated Salary)  
- Target variable: **Exited (0 = Stayed, 1 = Churned)**  

### 🔹 Business Problem
Banks often lose customers due to poor retention strategies. Identifying customers who are most likely to churn can help banks take proactive measures.  

### 🔹 Goal of the Project
To develop a **predictive ML model** that:
- Accurately classifies customers into “Churn” or “Not Churn”.  
- Provides interpretable insights into churn drivers.  
- Helps banks reduce customer attrition.

## 📊 Machine Learning Workflow
- **Data Preprocessing**: Handling missing values, encoding categorical features, scaling numerical data.  
- **Exploratory Data Analysis (EDA)**: Visualizing churn distribution, correlations, and key drivers.  
- **Feature Engineering**: Label Encoding & One-Hot Encoding.  
- **Model Building**: Logistic Regression, Random Forest, and other ML models.  
- **Model Evaluation**: Accuracy, Precision, Recall, F1-score, Confusion Matrix.
